# 唐诗异文与衍生引文编校

校录书目与出版摘录采用 UTF-8 编码，人物、单位和记录均为合成内容。

| 资料 | 字段 |
| --- | --- |
| `资料/校录.json` | `id`、`work`、`edition`、`line`、`text` |
| `资料/字形与底本.json` | `id`、`edition`、`text` |
| `资料/讲解稿.json` | `id`、`format`、`text` |

每份资料是 JSON 数组。记录中的字段值按来源原样保留为字符串，逗号和顿号可以属于字段内容。资料中可能有转述、不同的拼写以及较晚录入的更正。数字及日期在这些文件中沿用各资料自身的含义；原文位置以记录编号及文本范围定位。

Node.js 22 环境下运行以下命令可安装锁定的项目环境、检查素材格式并读取各类资料的数量。

```sh
npm ci --offline --ignore-scripts --no-audit --no-fund
npm test
npm run materials
```

`readMaterials` 只读取资料，不解析其中的正文含义。编校查询另由 `lib/` 与 `bin/cli.js` 提供。

## 核心约定

检索以「同一底本的连续原行」为单位，任何对外结果都同时携带底本名、行次与原字，绝不跨底本拼接。

- **底本谱系**：`字形与底本.json` 说明每个底本是原录、同一见证的补校，还是独立抄本。补校本（如“石录补校”）与父本（“石录”）同属一个见证，其差异才有资格作为勘误候选；独立抄本的差异始终是并列异文。
- **异体字**：只用于比对。命中异体字时结果会列出底本实际字形（如 `疎`）与所查字形（如 `疏`），并要求引用照底本原字。
- **正文与旁列**：`compare` 将所选底本正文与旁列异文分开列出；补校差异单独标注“须编辑裁定”。
- **改写关系**：讲解稿中的白话转述只作为理解线索，标为 `nonLiteral`，不能加引号冒充原文；白话与引文所用底本不同时会单独报告。
- **半句**：只匹配到原行一部分时，结果给出完整原行与行次，并提示不得截取半句。
- **跨底拼合**：各句分别落在不同底本或不同作品时，结果为 `conflated`，不产生任何整联依据，只逐句给出各自出处。

## 命令

```sh
node bin/cli.js <命令> [参数] [--json]
```

| 命令 | 作用 |
| --- | --- |
| `search <检索词> [--work 作品] [--edition 底本]` | 按底本原行检索，区分整行、半句、异体命中与跨底拼合 |
| `line <作品> <底本> <行号>` | 取一条已校录原行及引用信息 |
| `compare <作品> <行号>` | 对照该行各底本读法，正文与旁列异文分列 |
| `scripts` | 抽取讲解稿中的引文、白话转述与词义解释依据 |
| `audit` | 编校审计：问题、需编辑裁定事项与再印调整点 |
| `exhibit <作品> <底本> <起行> <终行>` | 校验展签底本的整联文字、分行及讲解稿是否同属一版 |
| `qr <检索词> [--work 作品]` | 二维码答复：底本、原行、匹配原因与提示 |
| `link <作品> <底本> <起行> [终行]` | 生成引用链接与二维码校验结果 |
| `resolve-link <作品> <底本> <起行> <终行> [--text 旧文字]` | 解析旧链接；文字已变时给出再印裁定点 |
| `legacy <检索词>` | 解析旧手册裸检索词；拒绝跨底拼合 |
| `assess <作品> <底本> <行号> <新录文>` | 判断新校录是独立旁证还是旧录有误，并列出受影响说明 |

### 常用示例

```sh
node bin/cli.js search "渔灯照疏岸，风定泊秋舟"   # 异体命中，给出石录原字“疎”
node bin/cli.js search "渔灯照疏岸，潮平过晚舟"   # 跨作品拼合，拒绝给出整联
node bin/cli.js compare 渡曲 2                    # 石录正文 + 抄本旁列 + 补校候选
node bin/cli.js audit                             # 再印需裁定之处
node bin/cli.js qr "渔灯照疏岸，风定泊秋舟"
node bin/cli.js assess 渡曲 石录 2 风静泊秋舟
```

## 状态值

| 状态 | 含义 |
| --- | --- |
| `attested` | 同一底本连续行逐字支撑（标点不计） |
| `attested-via-variant` | 仅经异体字归一才相合，须照底本原字引用 |
| `attested-fragment` | 只找到半句依据，已给出完整原行 |
| `conflated` | 各句分属不同底本或作品，任何一版都没有刊载这条整联 |
| `non-contiguous` | 各行在底本中不相邻，不能略去中间行 |
| `other-work-only` | 标注作品下无依据，原文在另一作品 |
| `paraphrase-only` | 只有白话近似，不能作原文引用 |
| `not-found` | 无任何依据 |

## 新校录改正一字时的判定

`assess` 与 `audit` 将「改正一字」区分为以下几种，对新海报与已沿用白话说明的影响不同：

| 判定 | 旧录 | 新海报 | 白话说明 |
| --- | --- | --- | --- |
| `independent-variant` | 未被否定 | 可并列，不可取代 | 保留，引用时注明另本 |
| `claimed-prior-error-unconfirmed` | 暂不否定 | 待编辑裁定 | 暂不据改 |
| `prior-error-proven` | 已证明有误 | 应采用改正读法 | 须复核改写 |
| `same-witness-variant` | 待定 | 待编辑裁定 | 暂不据改 |

只有同一见证且确有独立旁证时才判为 `prior-error-proven`；仅有补校自述而无旁证时，一律留待编辑裁定。

## 旧链接与再印

`link` 生成的链接记录版本、作品、底本、起止行与签发时文字。`resolve-link` 始终按链接记录的底本与行次定位，不会改用其他底本代填：

- `ok`：链接文字仍与底本一致。
- `superseded`：底本文字已变，返回现存文字与链接原载文字，并给出 `READING_SUPERSEDED` 或 `SENSE_EXPLANATION_AFFECTED` 等再印裁定点。
- `broken`：行次或底本缺失，明确指出缺哪一处。

旧手册中的裸检索词经 `legacy` 解析；若落在不同底本，返回 `refused-conflated` 并附逐句出处，不生成拼接引文。
